# API conventions

The interactive, always up-to-date reference is generated by FastAPI at
`http://localhost:8000/docs` (OpenAPI JSON at `/openapi.json`). This page
records the conventions that the generated docs do not show.

## Basics

- Base path: `/api/v1`. A breaking change would go under a new version prefix.
- Requests and responses use JSON.
- Field names use `snake_case`.
- Money is an integer number of XAF (FCFA), e.g. `"price": 15000`.
  XAF has no minor unit, so there are no cents and no floats.
- Timestamps use ISO 8601 in UTC (e.g. `2026-10-03T14:30:00Z`).
- Responses must make sense to any client (web now, mobile later).

## Endpoints

### `GET /`

Identifies the API. It is not versioned.

```json
{
  "service": "kamerwear-api",
  "version": "0.1.0",
  "docs": "/docs",
  "health": "/api/v1/health"
}
```

### `GET /api/v1/health`

Liveness check. It does not query the database.

```json
{
  "status": "ok",
  "service": "kamerwear-api"
}
```

## CORS

Browsers may call the API only from origins listed in the backend
`CORS_ORIGINS` setting (comma-separated, default `http://localhost:3000`).
Credentials are allowed, so the wildcard `*` is rejected at startup.
