# Development guidelines

KamerWear was built with an AI coding assistant (Claude Code). This folder keeps
the instruction files that guided it, so the project rules stay in one place.

| File | Purpose |
| --- | --- |
| [CLAUDE.md](CLAUDE.md) | Project rules and conventions: architecture limits, money in integer XAF, API under `/api/v1`, security rules (no secrets in git), where code goes, and the checks to run before finishing a task |
| [nextjs-AGENTS.md](nextjs-AGENTS.md) | Note generated by Next.js 16: read the documentation bundled in `frontend/node_modules/next/dist/docs/` before using a Next.js API, because this version may differ from older guides |

These rules apply to anyone working on the code, human or tool.

Coding assistants look for these files in the repository root (`CLAUDE.md`) and
in `frontend/` (`AGENTS.md`). To use one again, copy the files back there.
